# 91|疯狂|高潮|对白|合集使劲快高潮了对白刺激

能够对抗这种雷电，绝对是修仙界的大佬级别，自己不会遇到了两位大佬斗法吧？
　　李念凡的额头突突跳动，内心有些忐忑。
　　此地不宜久留。
　　他一点也没有过去凑热闹的念头，只想着快快远离。
　　自己不过是一介凡人，光是余波就足够让自己化为灰灰了，找死才会凑过去。
　　正想着，天空中又是骤亮起来！
　　轰隆！
　　第三道雷电落下，比起前面两道，这次的雷电都有些发红，威力显然更强。
　　李念凡看得真切，雷电下好像真的有东西，而且似乎漂在天上飞。
　　“哪里来的修仙者，偏要在这里打架？”李念凡内心苦涩不已。
　　值得庆幸的是，雷电的地点一直没有移动，李念凡的心稍稍安定。
　　他抱着大黑，一人一狗相依为命。
　　在第九道雷电之后，天上的乌云终于开始散去，大雨停止，阳光倾洒而下。
　　李念凡沐浴在阳光之下，差点感动哭了，吓死老子了。
　　他不敢耽搁，走出山洞，就向着跟雷电相反的方向走去，速度飞快。
　　“大黑，快点。”李念凡催促道。
　　雨后的山路泥泞不堪，李念凡的鞋子和裤管上都沾上了烂泥，不过他依旧不敢减速。
　　谁知道身后那两个修仙者会不会发神经再打一架？
　　如果打到自己这边来自己铁定就凉了。
　　至于会不会有机缘？
　　李念凡表示不会拿自己的小命开玩笑。
　　穿过这片森林，前方出现了一条长长的湖泊，湖水如镜，好似一条长长的绸带般，自山间穿流而过。
　　沿着这条湖泊直走，就能够到达李念凡的四合院了。
